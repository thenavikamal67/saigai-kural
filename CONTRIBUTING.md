# Contributing to Saigai Kural

Thank you for your interest in contributing to Saigai Kural.

We welcome contributions in mobile development, machine learning, accessibility, testing, Tamil translations, documentation, and dataset quality.

## How to Contribute

1. Check the existing issues before starting.
2. Open an issue to discuss major changes.
3. Fork the repository.
4. Create a branch for your change.
5. Make your changes and add relevant tests.
6. Run the available tests.
7. Submit a pull request with a clear description.

## Coding Guidelines

- Write clear, readable code.
- Use meaningful variable and function names.
- Keep modules focused on one responsibility.
- Add tests for new functionality.
- Update documentation when behaviour changes.
- Avoid committing generated files and secrets.

## Dataset Contributions

- Provide the source and licence of the data.
- Obtain consent for participant recordings.
- Include labels reviewed by knowledgeable ISL users.
- Document variations and known limitations.
- Never upload private or unauthorised recordings.

## Pull Requests

Explain the problem being solved, the changes made, and the tests performed. Do not claim recognition improvements without appropriate evaluation.

## Questions

Open a GitHub issue to discuss a bug, feature request, or contribution.
