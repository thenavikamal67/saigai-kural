# Saigai Kural Mobile Application

This directory is reserved for the Flutter mobile application.

## Planned Screens

1. Login
2. Home
3. Recognize
4. Learn
5. Settings and accessibility

## Planned Recognition Workflow

Camera input → Hand landmarks → Feature processing → Trained model → Tamil and English output → Optional speech.

## Development Status

The complete Flutter application has not yet been included in this starter repository.

To initialise the Flutter project, install Flutter and run:

```bash
flutter create .
flutter pub get
flutter run
```

Run these commands inside this directory after confirming it is ready for project initialisation.

The camera integration, model inference, vocabulary screens, authentication, and text-to-speech features must be implemented and tested before they can be considered functional.
